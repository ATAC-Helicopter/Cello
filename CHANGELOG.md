# Changelog

## 0.1.0-rc.1 — 2026-10-16

First public preview of Cello for GNOME Shell 46.

- Desktop battery card with charge rings, device icons and up to six devices.
- Automatic wallpaper tint, manual light/dark appearance and four corner positions.
- Native context menu through right-click, menu button and focused keyboard access.
- Passive BlueZ cache subscriptions, batched events and no recurring polling timer.
- Optional asynchronous Keychron bridge reading with explicit estimated/unknown/stale states.
- Cached asynchronous wallpaper thumbnail; unchanged data preserves actors.
- English and Italian translations.
- GPL-3.0-or-later licensing, source repository, CI and reproducible extension packaging.

GNOME Extensions submission and real installed-session/multi-monitor/HiDPI qualification remain open. Other Shell versions and device-autonomy metrics are not claimed.

### Release documentation and media supplement

A documentation-only supplement adds English/Italian user guides, screenshots captured from the released runtime, a GNOME listing draft, release notes and a downloadable media/documentation kit. It also ensures private-bus helper processes exit before temporary capture/test folders are removed. It does not change the extension archive or move the release tag.

# Cello 0.1.0-rc.1

Device batteries. At a glance.

![Cello on the GNOME desktop with simulated device readings](../media/releases/v0.1.0-rc.1/01-overview.png)

Cello puts Bluetooth device charge rings, icons and percentages on the GNOME desktop. Its native menu offers automatic/light/dark appearance and four corner positions.

This is a **public preview for GNOME Shell 46**. English and Italian are included. The GNOME Extensions submission is pending in [issue #1](https://github.com/ATAC-Helicopter/Cello/issues/1).

## Download and install

Download the extension ZIP and `SHA256SUMS` from this release, then:

```sh
sha256sum --check SHA256SUMS
gnome-extensions install --force keychron-batteries-widget@fglabs.local.shell-extension.zip
```

Log out and back in, then enable **Cello — Desktop Batteries**. This preserves the original widget UUID. An existing Keychron bridge is optional and is not bundled.

Read the [English user guide](https://github.com/ATAC-Helicopter/Cello/blob/main/docs/USER_GUIDE.md) or [guida italiana](https://github.com/ATAC-Helicopter/Cello/blob/main/docs/GUIDA_UTENTE.md). The release kit contains both guides, all public screenshots, captions, provenance manifests and listing material. It is separate from the installable extension ZIP.

## Background activity

Cello listens to information already in the BlueZ cache. It does not scan, pair, connect, issue GATT reads or write HID commands. It has no recurring polling timer. Unchanged data preserves the actor tree, and wallpaper decoding is asynchronous and cached.

A local 22-second idle observation counted zero additional BlueZ snapshots and zero widget rebuilds. This is not a measurement of watt usage, CPU/RAM overhead or device autonomy. The optional external bridge and BlueZ have independent behavior.

## Validation and limits

Lint, shell syntax, private-bus BlueZ event tests, deterministic ZIP checks and isolated GNOME 46 desktop tests passed for the runtime release. The CI covers real virtual-pointer menu events, placement, optional bridge lifecycle/stale expiry, automatic contrast and cleanup.

Public screenshots are captured from the released runtime in an isolated GNOME Shell with an original project wallpaper and clearly simulated device data. They demonstrate the interface; they do not qualify hardware readings or battery life.

Installed-session Wayland, real multi-monitor and HiDPI qualification remain in [issue #2](https://github.com/ATAC-Helicopter/Cello/issues/2). Other GNOME Shell versions are not declared supported. GPL-3.0-or-later.
